# ChickipDancersEnglish

Hello, this repo is for an English translation patch of "Chikippudansāzu norinoridansu de kokoro mo odoru" aka Chickip Dancers: Dance With Your Heart for Switch. This patch was made for Version 1.00 of the game. Tested on emu/hardware.

Download the latest release zip file and copy the contents to your atmosphere folder. Folder structure should look like this: SDROOT\atmosphere\contents\0100D85017B26000\romfs\Data\ files

This is fully complete as of Version 1.0, but if there is a bug or something I missed please feel free to report it and I'll take care of it. Please note that the video clips (opening cutscene/gameplay samples in menus) are NOT translated. At this time it is not possible to replace video clips in Unity.
